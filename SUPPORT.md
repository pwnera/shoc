# Getting help

shoc is a community project. There is no commercial support today.

| I want to… | Go here |
| --- | --- |
| Ask how something works | GitHub Discussions → Q&A |
| Report a bug | GitHub Issues → Bug report |
| Request a connector, rule or feature | GitHub Issues → the matching form |
| Report a vulnerability | See [`SECURITY.md`](SECURITY.md): never an issue |
| Propose a design change | An RFC in [`rfcs/`](rfcs/) |

Before opening an issue, please include your shoc version (`shoc --version`),
your backend, and the output of `shoc --json health status` with anything
sensitive removed.

Maintainers aim to give every first-time contributor a first response within two
business days, and to triage issues weekly.
